# DormFinder color palette

Approximate values taken from the design reference. Use the Figma eyedropper to fine-tune.

## Light theme
- Page background: #FFFFFF
- Warm panel (hero, tags, placeholders): #F3F0EC
- Soft background (navbar, footer): #F8F6F3
- Border: #E6E1DB, outline buttons: #CFC9C2
- Text: #111214, secondary text: #62666D
- Primary button and accents: #2D6AF0 (hover #1F57D6, pressed #1A49B8)
- Text links: #1F57D6
- Soft blue (chips): #E8F0FE with text #1C3F94
- Navy (charts, dark panels): #2C3A72
- Pastel panels: peach #F6E7DD, sky #E3EAF6, cream #F7EFD9
- Status: approved #2F9E6B, pending #F2B84B, rejected #E5636B

## Dark theme
- Page background: #101113
- Panel: #1B1D21, soft background: #15171A
- Border: #2C2F35, outline buttons: #3A3E45
- Text: #ECEDEF, secondary text: #A3A8B0
- Primary button: #2D6AF0 (hover #4A80F5), accent and links: #5B8CFF / #7FA3FF
- Soft blue (chips): #1B2A4D with text #BFD1FF
